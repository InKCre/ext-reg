## 0.5.1 - 2026-10-31

### Changed

- 冻结 v2 文档候选的指纹字段、默认值与 JSON 编码，Registry 和 Toolkit 共用纯算法，并以旧候选向量保护跨版本恢复。 (#documentation-identity)
- 原生发行的关联约束由生成的分发 union 校验；保留 Toolkit 的平坦模型构造、属性和序列化接口，拒绝缺失、混合或不匹配的原生关联。 (#native-contracts)

### Fixed

- 文档发布核对回执的原生坐标、候选内容和原始条件指纹，避免把结构合法但属于其他候选的回执报告为成功。 (#receipt)

## 0.5.0 - 2026-10-13

### Removed

- 原生分发独立准备和发布，退休旧统一版本写入入口；预览和文档按精确分发坐标读取。 (#native-release)

## 0.4.0 - 2026-09-22

### Added

- Generate static Registry Extension list and detail projections alongside exact releases. (#51)

## 0.3.0 - 2026-09-21

### Added

- 增加静态文档候选打包、幂等发布回执和文档发现；暂时性故障最多原样重试一次，无法确认时保留候选并报告结果未知。

## 0.2.1 - 2026-08-24

### Fixed

- Made static Preview Registry Release API paths reliably serve JSON on Cloudflare Pages.

## 0.2.0 - 2026-08-19

### Added

- Added the language-neutral installed Distribution contract and wheel finalization command.

### Changed

- Separated Extension developer tooling from Registry service and Host Runtime responsibilities.
