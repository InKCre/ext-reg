## 0.1.5 - 2026-09-18

### Fixed

- 通过 FastAPI route contexts 验证公开 HTTP 声明，兼容嵌套 router 并保持精确路径与撤销语义。

## 0.1.4 - 2026-09-17

### Added

- 新增配置、状态变更及启动的异步 Host 能力；复用 publication 作用域，在启动失败或取消时撤销本次资源，并保留旧同步 Host 入口。

## 0.1.3 - 2026-09-14

### Fixed

- 保留配置和 state 在一次操作中已经恢复的 typed 值，删除 bind/start 与内部传递的重复校验；真正的输入校验和持久表示恢复仍由原有边界处理。

## 0.1.2 - 2026-08-30

### Changed

- Keep imported capability type registrations process-monotonic while withdrawing only exact Extension routes, Peer inbounds, and public claims on stop.

## 0.1.1 - 2026-08-24

### Fixed

- Acquire the Extension wheel from its Registry without resolving dependencies
  there, then let pip install ordinary Python dependencies from its package
  index.

## 0.1.0 - 2026-08-19

### Added

- Established the Core Python Extension Host Runtime as an independent package.
